 Task API

A simple REST API built using Node.js and Express.

This project was created to practice backend fundamentals by implementing a complete CRUD API for managing tasks.

---

## Features

- GET / (API information)
- GET /health
- GET /tasks
- GET /tasks/:id
- POST /tasks
- PUT /tasks/:id
- DELETE /tasks/:id

---

## Technologies

- Node.js
- Express.js
